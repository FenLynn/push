本次按生产采集路径实际运行了全部 43 个 Finance 归档组，没有发现采集器级失败。历史补全遵循以下边界：

- 官方原始值优先，聚合传输或镜像只作为历史兜底。

- 国际机构估计与中国官方值分列保存，不能覆盖官方序列。
- 只有当前截面的指标不伪装成长序列，由 D1 从启用日开始前向积累。

## 仍不能自动补齐的部分

1. **婚姻季度表 2022Q4 以前**：民政部旧附件迁移后缺少稳定、可枚举的官方存档。年度数据已完整保留；不把年度值拆成四季。
2. **新能源车 2024 年以前月度**：CPCA 当前公开 API 仅返回滚动两年。网上流传的历史 Excel 多为付费或二次整理，无法验证版本链，不自动入库。
3. **经济活动人口旧口径**：旧年鉴能够零散补取，但历次人口普查后有回溯修订。下一步只能做“同版年鉴整段抽取 + 重叠年一致性校验”，不能拼接多个修订版本。
4. **早期城镇人口、老龄化年度空档、电力 2004—2005 少量月份**：官方表本身稀疏。可以显示断点，不能插值后标成官方值。
5. **新闻、行业一年涨幅等截面指标**：没有可验证的同口径历史 API，保留前向滚动存档。

## 自动更新策略

- 国家统计局、财政部、民政部、BIS 等源每次 Finance 完整任务重新读取；D1 以 `group + metric + period` 幂等覆盖，不产生重复行。
- 新数据先经过字段名、范围、起止期和空值验证；官方直连失败时才保留已经验证过的镜像历史。
- 审计脚本只读，不写 D1/R2，可用于工作流前后的覆盖回归检查。
