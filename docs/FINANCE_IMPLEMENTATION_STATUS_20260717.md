## 展示与存储边界

- D1 保存数值和统计期；R2 只滚动覆盖每项 `latest.png`。
- 月度、季度低频数据保留全历史；日度市场数据按既定窗口滚动。
- 图表不得用插值、随机数、硬编码总量或跨年差分填补缺口。
- “最新日期”是统计期，不冒充发布日期；股东模块同时保留统计截止日和公告日。
