# Estate 数据源维护说明

## 输出

`EstateSource` 汇总成都和西安的轻量房产指标，写入 `dashboard:snapshot:estate:latest`，同时沿用既有 D1 历史记录逻辑。

## 当前来源

- 成都：原成交页已迁移到 SPA。新网关要求浏览器端 SM2 签名，并限制客户端 IP；服务器请求会被官方入口拒绝。
- 西安：读取安居客公开在售页中的挂牌总量。页面存在反爬和结构变化风险。

## 降级规则

单个城市当天抓取失败时，只复用 KV 中 7 天内最近一次有效数据，不把历史值写成当天 D1 数据。小程序会在该指标后显示实际有效日期；超过 7 天后不再展示。

成都网关限制属于外部访问边界，当前采用最近有效快照降级，不通过伪造数据或在小程序中暴露签名材料绕过。
